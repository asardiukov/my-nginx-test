# Тестовое задание: Nginx X-Forwarded-For Chain & Anti-Spoofing

## Описание архитектуры
Стенд состоит из 3-х контейнеров Nginx (статические IP: `10.10.10.11`, `10.10.10.12`, `10.10.10.13`) и приложения-эхо `traefik/whoami` (`10.10.10.20`), которое выводит полученные заголовки.
Порты проброшены на хост: Nginx1 (8081), Nginx2 (8082), Nginx3 (8083). IP хоста в сети docker (шлюз) — `10.10.10.1`.

Для защиты от подмены заголовка `X-Forwarded-For` злоумышленником использована связка модулей Nginx: `geo` и `map`. 
Nginx доверяет только IP-адресам внутренних нод. Если запрос приходит извне, Nginx **перезаписывает** заголовок реальным IP пользователя. Если запрос передается между нодами — IP честно добавляется в цепочку.

---

## Протокол тестирования (curl)

Запуск стенда: `docker-compose up -d`

### Тест 1: Прямой запрос без подмены (пользователь > nginx1 > приложение)
**Команда:**
`curl -s http://localhost:8081/ | grep X-Forwarded-For`
**Результат:**
`X-Forwarded-For: 10.10.10.1`
*Вывод: Приложение получило реальный IP пользователя (шлюза docker).*

### Тест 2: Попытка подмены IP злоумышленником (пользователь > nginx1 > приложение)
**Команда:**
`curl -s -H "X-Forwarded-For: 8.8.8.8" http://localhost:8081/ | grep X-Forwarded-For`
**Результат:**
`X-Forwarded-For: 10.10.10.1`
*Вывод: Nginx распознал недоверенный источник, отбросил фейковый IP 8.8.8.8 и записал реальный IP пользователя. Защита работает.*

### Тест 3: Короткая цепочка (пользователь > nginx1 > nginx2 > приложение)
**Команда:**
`curl -s http://localhost:8081/to-n2/ | grep X-Forwarded-For`
**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.11`
*Вывод: Цепочка сформирована корректно. Приложение видит IP пользователя (10.10.10.1) и транзитного Nginx1 (10.10.10.11). IP последнего прокси (Nginx2) приложение может получить штатно из TCP-соединения (`RemoteAddr`).*

### Тест 4: Длинная цепочка (пользователь > nginx3 > nginx1 > nginx2 > приложение)
**Команда:**
`curl -s http://localhost:8083/to-n1/to-n2/ | grep X-Forwarded-For`
**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.13, 10.10.10.11`
*Вывод: Полная цепочка зафиксирована. Маршрут отслежен верно.*

### Тест 5: Попытка подмены при длинной цепочке
**Команда:**
`curl -s -H "X-Forwarded-For: 9.9.9.9" http://localhost:8083/to-n1/to-n2/ | grep X-Forwarded-For`
**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.13, 10.10.10.11`
*Вывод: Фейковый IP отброшен на входе (на Nginx3), дальше по цепочке передаются только реальные доверенные IP-адреса узлов.*
