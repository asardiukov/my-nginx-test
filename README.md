# Тестовое задание: Nginx X-Forwarded-For Chain & Anti-Spoofing

## Описание архитектуры
Стенд состоит из 3-х контейнеров Nginx (статические IP: `10.10.10.11`, `10.10.10.12`, `10.10.10.13`) и приложения-эхо `traefik/whoami`, которое выводит полученные HTTP-заголовки. 

**Безопасность сети:** Наружу (на хост) проброшен только порт входного узла — **Nginx1 (8081)**. Nginx2 и Nginx3 работают в изолированной Docker-сети (`10.10.10.0/24`), имитируя защищенный внутренний контур. IP хоста (шлюза) в сети Docker — `10.10.10.1`.

Для защиты от подмены заголовка `X-Forwarded-For` злоумышленником использована связка модулей Nginx: `geo` и `map`. 
Единая конфигурация Nginx доверяет только IP-адресам внутренних нод. Если запрос приходит извне, Nginx **игнорирует** пользовательские заголовки и записывает реальный IP клиента. Если запрос передается между доверенными нодами — IP честно добавляется в цепочку.

## Протокол тестирования (curl)

### Тест 1: Прямой запрос без подмены (Пользователь -> Nginx1 -> Приложение)

**Команда:**

```bash
curl -s http://localhost:8081/ | grep X-Forwarded-For

```

**Результат:**
`X-Forwarded-For: 10.10.10.1`
*Вывод: Приложение получило реальный IP пользователя (шлюза docker).*

### Тест 2: Попытка подмены IP злоумышленником (Anti-Spoofing)

**Команда:**

```bash
curl -s -H "X-Forwarded-For: 8.8.8.8" http://localhost:8081/ | grep X-Forwarded-For

```

**Результат:**
`X-Forwarded-For: 10.10.10.1`
*Вывод: Nginx распознал недоверенный источник (IP шлюза не входит в белый список внутренних узлов), отбросил фейковый IP 8.8.8.8 и записал реальный IP.*

### Тест 3: Короткая цепочка (Пользователь -> Nginx1 -> Nginx2 -> Приложение)

**Команда:**

```bash
curl -s http://localhost:8081/to-n2/ | grep X-Forwarded-For

```

**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.11`
*Вывод: Цепочка сформирована корректно. Nginx2 доверяет Nginx1 (10.10.10.11) и сохраняет IP пользователя.*

### Тест 4: Длинная цепочка (Пользователь -> Nginx1 -> Nginx2 -> Nginx3 -> Приложение)

**Команда:**

```bash
curl -s http://localhost:8081/to-n2/to-n3/ | grep X-Forwarded-For

```

**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.11, 10.10.10.12`
*Вывод: Полная цепочка зафиксирована. Запрос прошел через все три узла маршрутизации, каждый узел честно добавил IP предыдущего передатчика.*

### Тест 5: Попытка подмены при длинной цепочке

**Команда:**

```bash
curl -s -H "X-Forwarded-For: 9.9.9.9" http://localhost:8081/to-n2/to-n3/ | grep X-Forwarded-For

```

**Результат:**
`X-Forwarded-For: 10.10.10.1, 10.10.10.11, 10.10.10.12`
*Вывод: Фейковый IP мгновенно отброшен на входной точке (Nginx1). Внутренний контур остается чистым, передаются только реальные доверенные IP-адреса.*
